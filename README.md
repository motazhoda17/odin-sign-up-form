# Sign-up Form

A sign-up page for an imaginary service, built for [The Odin Project](https://www.theodinproject.com/lessons/intermediate-html-and-css-sign-up-form) Intermediate HTML and CSS course.

## Features

- Two-column form built with Flexbox
- Built-in HTML validation: required fields, `type="email"`, `type="tel"`, passwords with `minlength="8"`
- Blue border and shadow on the field you're typing in (`:focus`)
- Red border on invalid fields, only after you've interacted with them (`:user-invalid`)
- The Create Account button sits outside the form and still submits it using the `form` attribute

Password matching isn't checked yet. That needs JavaScript, which comes in a later lesson.
